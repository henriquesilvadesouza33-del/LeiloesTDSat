# LeiloesTDSat — Sistema de Gestão para Casa de Leilões

Sistema informatizado desenvolvido em Java para automatizar e gerenciar as rotinas de cadastro, controle e vendas de produtos de uma casa de leilões.

## Tecnologias Utilizadas
- **Linguagem:** Java
- **Banco de Dados:** MySQL (`uc11`)
- **Versionamento:** Git e GitHub
